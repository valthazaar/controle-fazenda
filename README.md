# Sistema de Controle de Fazenda

Projeto desenvolvido em Python utilizando SQLite e Programação Orientada a Objetos.

## Funcionalidades

- Cadastro de animais
- Listagem de animais
- Atualização de dados
- Exclusão de animais
- Registro de pesagens
- Histórico de pesagens

## Tecnologias

- Python 3
- SQLite
- Orientação a Objetos

## Como executar

python main.py
